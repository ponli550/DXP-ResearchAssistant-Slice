      Using the desk

      Reports
      Choose what to search from the question box. Open the side panel to browse and read them.
      Ask
      Type a question. You see the real work as it happens, then an answer with its page, or a plain "no answer".
      Citations
      Hover to preview the quote. Select to open the page with the quote highlighted. A line links them for a moment; hover either end to see it again.
      Uploads
      Add a PDF from the + menu, or drop it on the page. It is searchable only by the user who added it, and deleting it removes its text and the answers that used it.
      Tables
      Choose "Table across reports" in the question box to run one question in every report and see how a figure moved.
